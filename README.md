# CI Diagnosis Agent

A Week 1 AI-native project for diagnosing CI integration-test failures under incomplete information.

## Current status

Research/design draft. Human discussions and experiments are still pending.

## Repository structure

- `research-file.md` — living research
- `discussion-record.md` — Reddit/X evidence
- `review-record.md` — AI review decisions
- `decisions/probability-decision-record.md` — probability decision record
- `src/` — agent implementation
- `data/` — labeled/simulated cases
- `experiments/` — experiment scripts/configuration
- `results/` — predictions and evaluation
- `paper/` — eventual LaTeX preprint
- `social/` — eventual public posts

## Reproducibility

Will be completed after the baseline and experiment exist.

## AI use

AI is used for research assistance, question preparation, design review, coding assistance and later review. Claims, discussions and test results are not treated as real until verified.
